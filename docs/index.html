الأرصدة محسوبة من دفتر الأستاذ مباشرة، وليست مخزّنة في عمود منفصل.

الفاتورة تُحفَظ كمسودة ثم تُرسَل للمراجعة. لا تدخل الدفاتر إلا بعد اعتماد المراجِع — وعندها تصبح غير قابلة للتعديل.

البنود

من أنشأ المستند لا يستطيع اعتماده. الاعتماد هو لحظة الترحيل إلى دفتر الأستاذ.

قيود مرحّلة، غير قابلة للتعديل أو الحذف. التصحيح يتم بقيد عكسي.

إصدار الفاتورة منفصل عن إرسالها للمصلحة: البيع يتم فوراً، والإرسال يلحق به. الطابور يعيد المحاولة تلقائياً عند انقطاع الاتصال.

الضمانات التالية مفروضة داخل قاعدة البيانات نفسها، لا في كود التطبيق. اضغط أي زر لتشغيل العملية الممنوعة فعلياً ورؤية رد قاعدة البيانات.
